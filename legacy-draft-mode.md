# Legacy Draft Mode Documentation

## Overview

The **World Cup Legacy Draft** is an offline, single-player drafting mini-game embedded within the 256-team World Cup knockout simulator. Users draft a historic 11-player starting XI and then simulate it in an 8-team knockout tournament against elite AI opponents.

It is called "legacy" because it uses **historic World Cup data** -- real player names, ratings derived from EA Sports FIFA games, and actual opening-match lineups from past World Cups.

---

## Entry Points

### Triggering Legacy Mode

- **UI Button**: Clicking "Start legacy draft" (`#startLegacyDraftButton`) on the home screen
- **URL**: Navigating to `?mode=legacy` directly
- **Initial load**: If `?mode=legacy` is in the URL on page load

### Exiting

- "Back to modes" button sets URL to `?mode=home`

### Code Entry

```js
// app.js:584-599
function currentAppMode() {
  const mode = new URLSearchParams(window.location.search).get("mode");
  return mode === "online" || mode === "standard" || mode === "legacy" ? mode : "home";
}
```

The main `render()` function (line 6182) routes to `renderLegacyDraftMode()` when `currentAppMode() === "legacy"`.

### `LEGACY_NATIONS` (app.js:322-343)

Processed at load time from `window.LEGACY_HISTORIC_DATABASE`, enriching each player with:

| Field | Description |
|---|---|
| `id` | Composite key `{nationId}-{year}-{slugified-name}` |
| `year` | Squad year |
| `position` | Shorthand of `primaryPosition` |
| `positions` | Array: `[primaryPosition, ...secondaryPositions]` |
| `rating` | `overall` value |
| `stats` | Derived from attributes (`attack`, `control`, `defence`) |

### `LEGACY_FORMATIONS` (app.js:249-318)

| Formation | Slots |
|---|---|
| 4-3-3 | GK, LB, CB, CB, RB, CM, CM, CM, LW, ST, RW |
| 4-4-2 | GK, LB, CB, CB, RB, LM, CM, CM, RM, ST, ST |
| 3-5-2 | GK, CB, CB, CB, LM, CM, CM, CM, RM, ST, ST |
| 5-3-2 | GK, LWB, CB, CB, CB, RWB, CM, CM, CM, ST, ST |

Each slot has `id`, `label`, and `accepts` (array of compatible position codes).

## Full Code Flow

### Phase 1: Setup Screen

**Condition**: `currentAppMode() === "legacy"` AND `legacyDraft === null`

1. `renderLegacyDraftMode()` (app.js:5987) builds the setup UI:
   - Mode selector (Classic / Expert)
   - Formation selector (4-3-3 / 4-4-2 / 3-5-2 / 5-3-2) with random button
   - Country grid of 10 nations with "Ready"/"Review" status badges
   - Nation search input
   - "Start draft" button

2. Event listeners attached:
   - `[data-legacy-mode]` → updates `legacySetup.mode`
   - `[data-legacy-formation]` → updates `legacySetup.formationId`
   - `[data-legacy-random-formation]` → picks random formation
   - `[data-legacy-nation]` → updates `legacySetup.nationId`
   - `[data-legacy-random-nation]` → picks random playable nation
   - `[data-legacy-start]` → calls `startLegacyDraft(legacySetup.nationId)`
   - `[data-legacy-country-search]` → filters nation cards by name

3. "Start draft" button is **disabled** if the selected nation has 0 ready squads.

4. User clicks "Start draft" → `startLegacyDraft(nationId)` (app.js:2746):
   - Clears any spin timers
   - Calls `createLegacyDraft(nationId)` to build the `legacyDraft` object
   - Sets URL mode to `"legacy"`
   - Calls `render()` → `renderLegacyDraftMode()`
   - Now `legacyDraft` exists, so setup transitions to gameplay

### Phase 2: Draft Gameplay

**Condition**: `legacyDraft` exists AND `legacyDraft.complete === false`

1. `renderLegacyDraftMode()` renders the draft screen:
   - **Pitch visualization** with 11 clickable slots
   - **Round counter** (e.g., "Round 3/11")
   - **Year ticker** (spinning year display)
   - **"Spin for squad" button**
   - **Nation name + World Cup year**
   - **Offer grid**: 11 player cards

2. **Display modes**:
   - **Classic**: Shows PAC, SHO, PAS, DRI, DEF, PHY attributes + OVR badge
   - **Expert**: Shows only name, position, year (no numeric ratings)

3. Event listeners:
   - `[data-legacy-action='spin']` → calls `spinLegacySquad()`
   - `[data-legacy-offer]` → calls `selectLegacyOffer(playerId)`
   - `[data-legacy-slot-click]` → calls `handleLegacySlotClick(slotId)`

#### Spin Flow

**`spinLegacySquad()`** (app.js:2761):
- Checks not already spinning, no existing offers, not complete
- Sets `spinning = true`, clears `selectedOfferId` and `movingSlotId`
- If reduced-motion preference: instantly calls `nextLegacyOffers()`
- Otherwise: animates year ticker through available years (85ms interval) for ~1700ms, then calls `nextLegacyOffers()`

**`nextLegacyOffers()`** (app.js:2717):
- Gets empty slots via `legacyEmptySlots()`
- Shuffles draftable squads (only `dataStatus === "ready"`)
- Finds a squad where at least one undrafted player fits an empty slot
- Sets `currentSquad`, `yearTicker`, `offers` (all 11 players), stops spinning, reveals offers
- If no squad works: sets `blockedMessage`

#### Player Selection Flow

1. User clicks an offer card → `selectLegacyOffer(playerId)` (app.js:2810):
   - Toggles `selectedOfferId` (select/deselect)

2. User clicks an empty pitch slot → `handleLegacySlotClick(slotId)` (app.js:2825):
   - If `selectedOfferId` is set: calls `draftLegacyPlayer(selectedOfferId, slotId)`
   - Places player in slot, adds to `draftedIds`
   - If all 11 slots filled: sets `legacyDraft.complete = true`
   - Otherwise: increments `round += 1`, clears offers for next spin

#### Position Compatibility

**`legacyPlayerFitsSlot(player, slot)`** (app.js:2662):
- Returns `"natural"` if primary position matches slot's accepted positions
- Returns `"secondary"` if a secondary position matches
- Returns `null` if no match

**`legacyEffectiveValue(player, slot, value)`** (app.js:2673):
- Applies `LEGACY_SECONDARY_POSITION_PENALTY` of **-2** to the effective rating when playing a secondary position

#### Rearranging Players

Clicking a **filled** slot → `selectLegacyFilledSlot(slotId)`:
- Sets `movingSlotId`, then clicking another slot swaps players if both positions are compatible

### Phase 3: Draft Complete & Tournament

**Condition**: `legacyDraft.complete === true`

1. `renderLegacyDraftMode()` shows:
   - **Overall Rating**: `legacyOverallRating()` -- average of effective player ratings
   - **Chemistry Score**: `legacyChemistryScore()` -- from year-link bonuses and position fit bonuses
   - **Rearrange** functionality
   - **"Simulate 8-team tournament"** button
   - **"Restart draft"** button

2. **`runLegacyTournament()`** (app.js:2915):
   - Builds `customTeam` via `legacyDraftTeam()` (app.js:2874):
     - Maps drafted lineup into a simulation-compatible team object
     - Computes: overall, attack, midfield, defence, goalkeeper, squadDepth, experience, penalties, discipline
     - Uses `TEAM_BY_ID` map to temporarily insert the custom team (`id: "legacy-{nationId}-xi"`)
   - Shuffles 7 elite opponents (Brazil, France, Germany, Argentina, Italy, Netherlands, Portugal, Spain)
   - Simulates a 3-round (8-team) single-elimination bracket using `simulateMatch()`
   - Stores results in `legacyDraft.tournament`
   - Displays bracket results on screen

3. **Restart**: Sets `legacyDraft = null` and re-renders setup screen.

## Game Modes

### Classic Mode
Shows all player data: PAC, SHO, PAS, DRI, DEF, PHY attributes and OVR rating badge on offer cards and drafted slots.

### Expert Mode
Hides numeric ratings. Only shows: name, position, World Cup year on offer cards. Drafted slots show only name and position. Requires evaluating players based on football knowledge rather than numbers.

---

## Build Pipeline

1. Source data: `legacy-data/nations/{nation}/{year}.json` files (one per nation-year combination)
2. Generate: `npm run generate:legacy-data` reads JSON files → generates `legacy-data/catalog.generated.js`
3. Validate: `npm run test:legacy-data` checks data integrity
4. Smoke test: `npm run smoke-test` runs deterministic draft completion test
5. At runtime: `index.html` loads `catalog.generated.js` → `window.LEGACY_HISTORIC_DATABASE` populated → `app.js` processes into `LEGACY_NATIONS`

## Legacy vs Standard Mode

| Aspect | Standard Mode | Legacy Draft Mode |
|---|---|---|
| Teams | 256 modern teams | User-drafted XI + 7 AI opponents |
| Format | Full 8-round single elimination | 3-round (8-team) mini-tournament |
| Players | Pre-defined per-team pools | User drafts from historic squads |
| UI | Match stage, fixture board, storylines | Draft pitch, offer cards, spin mechanic |
| State | `state` object (localStorage persisted) | `legacyDraft` (in-memory only) |
| URL | `?mode=standard` | `?mode=legacy` |
| Settings | Upset level, goal level, etc. | Mode, formation, nation |
| Simulation | Real-time playback with spoiler shield | Instant simulation |
